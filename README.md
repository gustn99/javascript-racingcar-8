# javascript-racingcar-precourse

## 구현 목록

### 사용자 입력

- [ ] 이름 입력
  - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
  - [ ] 빈 문자열 ERROR
  - [ ] 중복 이름 ERROR
  - [ ] 빈 이름 ERROR
  - [ ] 5글자를 초과한 이름 ERROR
- [ ] 횟수 입력
  - `시도할 횟수는 몇 회인가요?`
  - [ ] 빈 문자열 ERROR
  - [ ] 숫자 외 ERROR
  - [ ] 양수 외 ERROR (0은 경주 시작 x)

### 경주

**경주 전**

- [ ] 이름별 자동차 생성

**경주 중**

- [ ] 시도 횟수만큼
  - [ ] 차별로
    - [ ] 0-9 사이 난수 생성
    - [ ] 4 이상 전진 / 4 미만 정지
    - [ ] 현재 위치 저장
  - [ ] 전체 현재 위치 출력

**경주 후**

- [ ] 최종 위치 비교, 우승자 선정
- [ ] 우승자 출력 (여러 명이면 `, `로 구분)

### 테스트

## 구현 목표

- [ ] 단일 책임 원칙을 적용하면서 좋은 구조 유지
- [ ] 콘솔 로깅 대신 디버거 사용
- [ ] 테스트 작성

## 프로그래밍 요구 사항

- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
- 힌트: indent(인덴트, 들여쓰기) depth를 줄이는 좋은 방법은 함수(또는 메서드)를 분리하면 된다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
