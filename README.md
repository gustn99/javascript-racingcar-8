# javascript-racingcar-precourse

기능 목록

1. 이름과 시도할 횟수 입력 받기
2. 주어진 횟수 동안 전진하기
    1. 0-9 사이 무작위 값 추출 -> 4 이상이면 전진, 미만이면 그대로
3. 라운드별 결과 출력
4. 우승자 출력

예외 처리

1. 이름이 없는 경우
2. 이름이 중복된 경우
3. 시도 횟수가 자연수가 아닌 경우
    1. 입력이 없거나
    2. 0 또는 0 미만
    3. 소수

테스트 사항

1. 라운드별 결과와 우승자를 올바르게 출력하는지
2. 횟수를 입력하지 않았을 때 예외가 발생하는지
